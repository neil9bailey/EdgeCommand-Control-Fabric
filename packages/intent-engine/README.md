# Intent Engine

This package seeds the E08 Automation Intent Partner.

It defines deterministic intent frames for the local Docker build:

- Water leak response.
- Narrowband fallback.
- Module enablement.
- Energy reserve protection.
- Security access governance.

The engine proposes only. It creates structured sessions, proposal cards, required gates, confidence labels, MCP tool plans, and KRA-ready critique context. It never executes physical commands, enables modules, or mutates infrastructure.
