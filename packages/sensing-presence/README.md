# Sensing And Presence

E17 promotes occupancy, presence, and environmental sensing into a governed foundation module.

It currently provides:

- Room occupancy and presence confidence.
- Air quality, CO2, PM2.5, VOC, temperature, and humidity observations.
- Privacy-aware presence modes.
- Intent-triggered sensing profile previews.
- MCP-ready context preview and privacy proposal boundaries.

The package is read by the API gateway through `sensingPresence.mjs`. E17 is telemetry and proposal first; it does not execute surveillance, camera, or invasive tracking actions.
